# Markdown 报告 PDF

用户希望复用固定排版，避免每次导出重新编写转换代码。直接使用 [scripts/export_pdf.py](scripts/export_pdf.py)，不要为普通报告重新制作专用脚本。课程作业的完整流程已整合到 [do-tsinghua-homework](../do-tsinghua-homework/SKILL.md)：默认先交付 Markdown，用户修改确认后再导出 PDF。本技能仍可独立处理已有 Markdown 的明确导出请求，这种请求已授权导出，无需再次确认。

## 默认排版与内容边界

- 每次读取用户最新保存的 Markdown，按其正文、题号、标题和图片路径导出。不要恢复用户删除的段落、姓名、参考文献，也不要擅自添加封面、摘要或其他内容。
- A4 纵向，约 18 mm 页边距。中文正文用 Songti SC Regular（宋体），12 pt、22 pt 行距；标题用黑体，英文用 Times New Roman。中文字体实际嵌入 PDF，避免仅引用 STSong-Light 导致阅读器替换字体或异常粗重。
- macOS 默认字体配置：Songti.ttc 的子字体 6 为简体常规、1 为简体粗体；STHeiti Medium.ttc 的子字体 1 为简体黑体。其他系统必须指定真实字体，不默默用缺少中文字形的字体替代。若当前应用提供 load_workspace_dependencies，优先使用其返回的 Python；其他环境使用装有 reportlab、Pillow 的 Python，预览额外需要 pypdfium2。跨系统字体参数及依赖安装方法见仓库 README。
- 图片从 Markdown 所在目录解析；支持相对/绝对路径、空格及 URL 编码。保留原图，不裁掉数据、标记、窗口元素，不拉伸、不用生成图替代截图。先用用户提供的图，只有用户要求时才修改图片。
- 图片按可用页宽等比缩放，过高则同时缩小宽高；图片和已有图注尽量同页。低清晰度会输出警告，先检查 PDF 中字段可读性，不为此自动处理图片。横图可正常等比嵌入，确需横向整页时使用 --landscape。
- 中文思考题以（1）或（１）等编号识别，将题目和随后短答案合为紧凑块，便于和截图共页。不要把课程要求的题号隐藏。普通段落首行缩进，图注、答案、列表不缩进。

## 快速使用

用获取到的 Python 路径执行；以下 python3 指代带有所需依赖的 Python：

```bash
python3 <skill目录>/scripts/export_pdf.py <最新Markdown路径> <PDF输出路径> --break-h1 --render-dir <临时预览目录>
```

--break-h1 用于阅读报告与实验报告这类并列一级章节，后续一级标题另起一页。短文、首个一级标题是总标题的文档不要机械加此选项。Markdown 中单独一行的 <!-- pagebreak --> 可以精确分页。

脚本支持标题、段落、常用行内加粗/斜体/代码/链接、简单列表、管道表格、围栏代码和本地图片。多级列表、复杂 HTML、公式等会报错；只在遇到这些实际需求时选合适转换方式，不把不支持的结构静默丢掉。

优先运行一次默认导出；图片或分页确实不合适时，再用 --compact、--image-max-height、--body-size 或 --leading 调整。不要为了固定页数把正文挤到难读。

## 交付检查

当前环境有 PDF skill 时，按其要求完成产物操作登记。导出后查看脚本生成的每页 PNG，确认中文无缺字、无溢出、标题与正文不分离、图片比例正确且关键字段可读。发现问题做局部参数调整，不重写全部流程。完成后打开 PDF，简短说明所用字体、页数和内容来自最新 Markdown。不要宣称已提交课程平台。
